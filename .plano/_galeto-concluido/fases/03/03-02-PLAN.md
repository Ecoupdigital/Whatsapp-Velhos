# Fase 03 Plano 02: Config de tipos de item no evento

**Objetivo:** Adicionar ao modal "Editar Evento" um campo "Tipos de item" que permite definir os tipos (ex: cru, assado) por CSV/chips e salva via `PUT /eventos/{id}` no campo `tipos_item`. Esses tipos governam as colunas dinamicas do grid (plano 03-04) e o card de estatistica (plano 03-03). Baixo risco: e uma adicao ao modal existente, nao mexe na listagem de participantes.

## Contexto

@frontend/src/app/(app)/eventos/[id]/page.tsx — modal "Editar Evento" em ~L1224-1364. `interface EditForm` em ~L93-110. `openEditModal` em ~L391-412 (preenche editForm a partir de evento). `handleEditSubmit` em ~L463-497 (monta `payload: EventoUpdate` e faz `api.put`).
@frontend/src/types/index.ts — `EventoUpdate.tipos_item?: string[] | null` e `EventoOut.tipos_item: string[] | null` (adicionados no plano 03-01).
@frontend/src/components/ui/Input.tsx — componente `Input` (props padrao de input HTML + `label`).

Convencoes: usar UI kit existente (`Input`), sem nova identidade visual. Toast via `react-hot-toast`. Idioma PT-BR sem em-dash.
